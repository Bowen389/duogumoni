# strategies2 — 第二批策略：C_top50 与 K_top3

与 `strategies/`（A_top50 / A_top20 / AE_top20）完全独立，互不修改。股票池仍然只有**中证1000**。

| 策略 | 一句话 | 适合 |
|---|---|---|
| **C_top50** | 三个散户行为模型（含新数据“股东户数”）集成，持 50 只，每天换 2 只 | 主力资金；A_top50 的升级版 |
| **K_top3** | 6 个 5 日模型集成，只持 3 只，指数走弱时全部空仓 | 小资金、能承受 30–40% 回撤；**先模拟盘** |

核心观点不变：**散户一直在犯同样的错**——追涨停、买彩票股（MAX20）、追放量、跟风热门、筹码分散到散户手里还继续买。
事件研究表明，这些“追”的行为之后 5 天平均都是负超额。所以**赚钱的方式是站到散户的对面：避开他们扎堆追的票，拿他们嫌弃的票**。

## 2. 必须知道的几件事（请先读完）

### ① 集中持仓并没有比分散赚得更多

用户的目标是“每天重仓 1–3 只，尽可能多赚”。做完全部实验后，诚实的结论是：

- **K_top3 和 C_top50 的收益差不多**，样本外还明显更差（13.0% 对 23.3%），回撤也不更小。
- 持 1–2 只时，大部分参数组合的最大回撤超过 40%，所以不满足“回撤 ≤ 40%”的要求，最终选了 3 只。
- 完全不择时，回撤高达 45–70%。空仓择时是控制回撤的必要条件，代价是牛市跑输。

原因：散户的错误主要表现为**“什么不该买”**（追涨、博彩），而不是“哪一只一定会涨”。
所以信号在分散组合里很稳，集中到 3 只就会被个股噪音淹没。

### ② 结果对模型非常敏感，20% 是区间的上沿

同一组参数（3 只、缓冲 60、3 票择时、开盘成交）换到 9 个模型变体上（不同随机种子、有无股东户数因子、不同集成方式）：

| | 最低 | 中位数 | 最高 |
|---|---|---|---|
| 研究期年化 | 2.6% | 约 13% | 20.2% |
| 样本外年化 | 9.7% | 约 13% | 26.4% |
| 最大回撤 | −21% | | −39% |

- 只是往模型里加了 6 个弱因子（股东户数），54 组参数的年化中位数就从 8.6% 掉到 1.0%。
- 为了避免事后挑出一个最好看的模型，K_top3 采用“全部 6 个 5 日模型等权集成”（h5ens6）。这是原则性的选择，不是挑出来的。
- **合理预期：年化约 13%，最大回撤 30–40%。**

### ③ 实盘模型最近一年表现差

实盘模型用 2015-01~2024-08 的数据训练，最近两年作验证期。

- 5 日模型早停时只选了 21–34 棵树，研究版是 90–200 棵，说明**最近两年 5 日信号明显变弱**。
- K_top3 实盘模型的一年模拟盘（2025-09~2026-09）：**−20.8%**，同期中证1000 −2.7%，最大回撤 −28%。同一时段研究版模型是 +7.7%。
- C_top50 实盘模型同一年的超额是 +10.7%，正常。

我没有为了让最近一年好看而调参数，那样会变成过拟合。建议：
**K_top3 先模拟盘跑 3–6 个月，或只放小资金；主力资金用 C_top50。**
每次运行 `signal` 都会打印最近一年的模拟盘表现，可以随时观察。

### ④ 股东户数：有效但增量小

东方财富的股东户数（`HN_*` 因子）方向稳定：

- 户数增加（筹码流向散户）→ 后续跑输；
- 户数减少 → 后续跑赢；
- 11 年里每年方向都一致，行业中性 ICIR 约 0.2，和已有因子的相关性不超过 0.16。

但放进模型后提升不大：Top50 超额研究期 +0.7%、样本外 +3.0%；Top20 分别 +0.1%、+3.6%。
C_top50 的提升主要来自**三模型集成**：散户因子、+行为因子、+股东户数，三个视角互相纠错。

注意：股东户数按**公告日**对齐（不是报告期截止日），不存在未来数据。

### ⑤ 融资融券数据：已抓取，未评估

`data_fetch/fetch_em.py margin` 可抓取中证1000 历史成分股的两融明细，`python -m engine.em_features margin` 可生成融资因子（输出到单独的 `feat_margin`，不影响现有模型）。
这部分**还没评估**，暂不用于任何策略。

人气榜只有近期数据，无法回测，已放弃；龙虎榜这次没有纳入，留待以后评估。

## 3. 每日使用

### 第一次

```bash
bash setup_env.sh                                # 行情和面板数据（与 A 系列相同）
bash strategies2/setup_data.sh                   # 股东户数：全量抓取（约 15 分钟）+ 生成因子
source env.sh
python strategies2/live.py train --strategy C_top50   # retail / rb 与 A 系列共用；已存在就跳过，只训 rbh
python strategies2/live.py train --strategy K_top3    # 6 个 5 日模型
```

内存小于 4GB 时，训练前请关闭其他程序；也可以逐个训练，例如 `--model k_rb_s0`。

### 每个交易日收盘后

```bash
bash setup_env.sh --refresh            # 更新行情
bash strategies2/setup_data.sh --refresh   # 增量更新股东户数（几秒）+ 重建因子
source env.sh

# C_top50：次日尾盘成交
python strategies2/live.py signal --strategy C_top50 --holdings my_c.csv --cash 12345 --etf_value 0

# K_top3：次日开盘集合竞价成交
python strategies2/live.py signal --strategy K_top3 --holdings my_k.csv --cash 12345
```

- 持仓文件格式：`code,shares`（如 `002484,900`，带不带 .SZ 都可以）。
- 清单保存在 `strategies2/signals/`（已加入 .gitignore，不会被提交）。
- 首次建仓不传 `--holdings`，默认资金 100 万（`config.py` 中的 `account`）。
- 两个策略请用不同账户，或分开记录持仓。

### K_top3 的规则

1. **择时**：中证1000 指数收盘站上 20/40/60/80/120 日均线中至少 3 条才持股，否则次日开盘全部卖出。
2. **选股**：6 个模型的原始打分（不做行业中性，保留小盘和低波的倾向）按排名等权平均。
3. **持仓**：最多 3 只、等权；持仓股排名跌出前 60 才卖，空出的位置补当日排名最高的股票。
4. **成交**：T 日收盘后出信号，T+1 开盘集合竞价成交（尾盘成交回测明显更差：11.7% / 7.3%）。
5. 买入目标一字涨停或停牌时，按清单里的替补顺序替换。

### C_top50 的规则

与 A_top50 相同：持 50 只、每天最多换 2 只、R3 回撤保护（超额回撤 −8% 时转 ETF，−4% 时恢复）、次日尾盘成交。唯一的区别是打分换成三模型集成。

### 重新训练

建议每半年到一年重训一次：`python strategies2/live.py train --strategy K_top3 --force`（加 `--valid_end` 指定验证期终点）。

## 5. 附：持股数量与择时（`experiments/timing_overlay.py` → `output/timing/`）

**持股数量**（不择时，年化 / 回撤，零滑点口径同上）：C_top20 研究期 13.1% / −38%、样本外 25.3% / −33%，不如 C_top50；
持 10 只、5 只两段都不稳定，5 只基本失效。**50 只仍是最好的选择。**

**择时**（中证1000 均线投票，T 日收盘判断、T+1 尾盘执行，千1滑点）：

| C_top50 | 研究期 年化 / 回撤 / 收益回撤比 | 样本外 |
|---|---|---|
| 满仓（现方案） | 16.4% / −34% / 0.48 | 21.6% / −30% / 0.72 |
| 固定半仓 | 8.7% / −18% / 0.48 | 11.0% / −16% / 0.68 |
| 投票≥3 → 空仓 | 7.5% / −18% / 0.42 | 1.7% / −26% / 0.07 |
| 投票≥4 → 半仓 | 12.2% / −25% / 0.49 | 15.2% / −16% / 0.93 |

- 择时在熊市（2022 年）和 2024 年 2 月小盘股崩盘时有用，但在 2020、2021、2025 年的上涨中损失很大（C_top50 2025 年 54.7% → 12.5%）。
- 研究期里，**任何择时的收益回撤比都不比“固定降低仓位”更好**，也就是说，择时只是用收益换回撤，并没有额外价值。
- “投票≥4 → 半仓”只在样本外更好，研究期没有提升，不算稳健；A、AE、持 20 只的组合结论相同。
- 对冲版（做空股指期货）按 10% 年化贴水估算，也比不择时差。
- “50 只一起下跌”是市场（beta）下跌，换股解决不了。多换几只以前测过，结果更差。**想要更小的回撤，最简单也最稳健的办法是降低总仓位**（例如 7 成仓：回撤约 −25%，年化约 12%）。

## 6. 附：逐只精选、最多 10 只、允许空仓（`experiments/p2p.py`、`p2p_prod.py` → `output/p2p/`）

测试了 288 组参数：打分（1 日集成 C / 5 日集成 H5 / 两者混合）× 共识过滤（两个周期都排进前 q 名才买）× 最多 5/10 只 × 缓冲 × 择时 × 开盘/尾盘 × −10% 止损；
另外做了邻域检验（k 3–10，M 30–300，止损 5–20%，滑点千1–千3），并用实盘模型检验最近两年。

- **288 组的年化中位数：研究期 0.4%，样本外 5.5%。** 大多数集中持股配置并不赚钱。
- 共识过滤、个股止损：**没有稳定效果**。1 日模型集中持股的中位数为负，只有 5 日模型可用；开盘成交优于尾盘。
- 表面上的最优组合（k5 / M60 / −10% 止损：研究期 22% / 样本外 41%）换一下邻近参数就跌到 2–4%，属于巧合。
- **比较稳健的区域：H5、不择时、最多 8–10 只、M 60–300、开盘成交**

| | 研究期 2023-26 | 样本外 2020-22 | 实盘模型 近一年（指数 +2.8%） | 实盘模型 近两年（指数 +68%） |
|---|---|---|---|---|
| 年化或累计 / 最大回撤 | 9–17.5% / −37% ~ −41% | 24–50% / −33% ~ −41% | +10% ~ +22% / −22% ~ −29% | +48% ~ +80% / −22% ~ −29% |

  滑点千3 时研究期只剩 4–11%。弱年份：2022 年 −8% ~ +14%，2023 年 +3% ~ +6%。
- 择时版（持 3–6 只）用实盘模型检验时，近一年 −20% ~ −4%，近两年远远跑输指数。**K_top3 的实盘版近一年 −20.4%，与第 2 节一致。**

# 模拟盘（每个策略独立 10 万账户）

由 GitHub Actions 每个交易日 17:00（北京时间）自动运行：用当天收盘价成交上一交易日的清单 → 盯市 → 生成下一交易日清单。
数据源当天没更新时会在之后的运行里自动补齐（按真实成交日价格）。说明见 [paper/HOWTO.md](HOWTO.md)。

# 模拟盘（每个策略独立 10 万账户）

> 执行v2：旧历史保留，切换日期见state.json的execution_start；[规则和限制](../EXECUTION_V2.md)。

由 GitHub Actions 每个交易日 21:15（北京时间）自动运行，23:15 / 次日07:15 重试：用当天收盘价成交上一交易日的清单 → 盯市 → 生成下一交易日清单。
日线使用社区批量数据包，状态按日期批量获取；数据不完整时任务报错，账户不更新。说明见 [paper/HOWTO.md](HOWTO.md)。

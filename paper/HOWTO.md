# 模拟盘说明

6 个策略各有一个独立的 **10 万元**模拟账户，由 GitHub Actions 在每个交易日**北京时间 17:00** 自动运行，严格按各策略自带的 `signal` 工具给出的清单操作。

| 账户 | 清单来源 | 成交方式 |
|---|---|---|
| A_top50 / A_top20 / AE_top20 | `strategies/live.py signal` | 下一交易日**收盘价**（尾盘集合竞价）；涨停/停牌买不进按顺序用替补；跌停/停牌卖不出就继续持有，第二天的清单会再卖 |
| C_top50 | `strategies2/live.py signal` | 同上 |
| K_top3 | `strategies2/live.py signal` | 下一交易日**开盘价**，滑点千1；股数按"目标金额 ÷ 开盘价"重新计算；开盘一字涨停/停牌用替补 |
| FB_dip | `strategies2/fb_live.py signal` | 下一交易日开盘价落在买入区间（低开 2%–7%）才买，低开越深越优先，最多 2 只、每只半仓；买入后下一个交易日收盘卖出（跌停/停牌顺延） |

**R3 风控**（A/C 系列）：清单提示进入半仓时，把每只持仓卖出约一半（按手取整；只有 1 手的仓位会逐手补卖，直到凑够目标），买入中证1000ETF；解除时卖出全部 ETF。ETF 没有单独的价格数据，用中证1000 指数的日收益近似。

**费用**：A/C/K 按各自 config（买万5、卖千1，每笔最低 5 元）；FB_dip 按研究口径（佣金万2.5、印花税万5、单边滑点千1）。

## 每天发生了什么

每次运行对每个还没处理的交易日 d 依次执行：

1. **成交**：执行上一交易日生成的清单，价格用 d 日的真实开盘价/收盘价
2. **盯市**：按 d 日收盘价估值（除权除息用复权因子把股数折算，相当于分红再投资，所以除权后股数可能带小数；复权因子变化小于 0.3% 的小额分红忽略）
3. **出清单**：用账户当前的真实持仓和现金调用策略的 `signal` 工具，生成 d+1 的清单

数据源 [chenditc/investment_data](https://github.com/chenditc/investment_data) 每天发布的时间不固定（过去两周在北京时间 16:17 到次日 03:49 之间）。
17:00 运行时如果当天数据还没发布，这次就不处理当天，**之后的运行会自动补上**，成交价仍然按当天的真实价格。
所以 workflow 在 17:00 之外还有两次补跑：21:00 和次日 08:30（账户已是最新时几十秒就结束）。不需要补跑的话，删掉 `.github/workflows/paper.yml` 里对应的两行 cron 即可。

## 文件

| 路径 | 内容 |
|---|---|
| `paper/README.md` | **总览**：各账户净值、收益、回撤，以及下一交易日的操作清单（每次运行自动更新） |
| `paper/accounts/<策略>/nav.csv` | 每日净值：现金、股票市值、ETF 市值、总资产、当日/累计收益、中证1000 对比 |
| `paper/accounts/<策略>/trades.csv` | 每一笔成交（含买不进、卖不出的记录） |
| `paper/accounts/<策略>/positions.csv` | 当前持仓 |
| `paper/accounts/<策略>/state.json` | 账户状态（现金、持仓、待执行清单），程序读写用 |
| `paper/signals/<日期>/<策略>.csv / .txt` | 当天各策略的完整清单和 signal 工具的原始输出 |
| `paper/sim.py` | 模拟盘程序 |
| `paper/run_daily.sh` | 每日流程：下载数据 → 面板/因子 → 股东户数增量 → 市场情绪 → 模拟盘 |
| `paper/data/extra/` | 行业分类和东方财富股东户数（每天增量更新并提交，避免每次全量抓 15 分钟） |
| `.github/workflows/paper.yml` | 定时任务 |

## 常用操作

- **手动运行**：GitHub 仓库 → Actions → "模拟盘每日运行" → Run workflow（勾选 force 会强制重跑）
- **重置某个账户**：删除 `paper/accounts/<策略>/` 目录并提交，下次运行会以 10 万元重新开始
- **改初始资金**：在 workflow 的 `env` 里加 `PAPER_CASH: 200000`（只对新建的账户生效）
- **本地运行**：`bash setup_env.sh && source env.sh && pip install baostock && bash paper/run_daily.sh`

## 需要知道的

- **10 万元对 A_top50 / C_top50 偏小**：50 只等权，每只约 1,900 元，股价高于约 19–28 元的股票买不起一手，清单会标"资金不足一手，用替补"。这会让持仓偏向低价股，和策略 README 里 100 万的回测有差距（策略 README 建议 50 万–300 万）。
- **K_top3 最近一年表现差**：策略 README 第 2 节写过，实盘模型的一年模拟盘是 −20.8%，这个账户很可能继续亏，属于预期内。
- 模拟盘按开盘价/收盘价成交，没有计入冲击成本和排队成交失败，实盘会更差。
- 仅供学习研究，不构成投资建议。
